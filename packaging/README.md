# Сборка PbReader в программу

## Одной командой (Windows)

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

На выходе:

| | |
|---|---|
| `dist\PbReader\` | программа целиком — работает как есть, каталог можно просто скопировать на аппарат |
| `dist\PbReader-0.1.0-setup.exe` | установщик, если в системе стоит [Inno Setup 6](https://jrsoftware.org/isdl.php) |

Собирать нужно **на Windows**. У PyInstaller нет кроссплатформенной сборки: он
кладёт внутрь интерпретатор и библиотеки той системы, где его запустили.
Разрядность берите ту же, что у аппаратов.

## Что получается

Два исполняемых файла рядом, с общими библиотеками:

| | |
|---|---|
| `PbReader.exe` | **без консоли** — его запускает человек с рабочего стола. Двойной щелчок открывает окно. Чёрное окно консоли поверх интерфейса киоска недопустимо, поэтому вывод уходит в журнал `%LOCALAPPDATA%\PbReader\pbreader.log` |
| `pbreader.exe` | **консольный** — его запускает основной проект и читает stdout. Полная командная строка: `print`, `serve`, `printers`, `preview` |

PDFium весит около восьми мегабайт, поэтому оба файла делят один каталог
библиотек, а не тянут по копии.

## Установщик

Ставит в `Program Files\PbReader`, добавляет ярлык в «Пуск», запись в
«Программы и компоненты» и удаление. Две галочки по желанию:

* **значок на рабочем столе**;
* **запускать сервис при входе в систему** — по умолчанию выключено. Обычно
  сервис поднимает основной проект сам, и второй экземпляр занял бы порт.
  Включать только на отдельно стоящем аппарате, и тогда **задайте `token` в
  `pbreader.json`**: при автозапуске stdout читать некому, а без токена к
  сервису не обратиться.

Настройки — `pbreader.json` рядом с программой; образец с пояснениями кладётся
туда же как `pbreader.example.json`. Журнал и настройки при удалении не
трогаются.

## Что проверить на аппарате после установки

```
pbreader.exe --version     запускается ли вообще
pbreader.exe printers      видит ли драйверы, совпадают ли номера лотков
PbReader.exe               открывается ли окно, идёт ли предпросмотр
```

Третий пункт важнее первых двух: он проверяет, что в сборку попала страница
окна и библиотека PDFium. Если окно открывается пустым — значит потерялась
страница; если предпросмотр не строится — PDFium.
